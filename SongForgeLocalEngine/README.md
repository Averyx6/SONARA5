# SongForge Local Engine

This replaces the paid ElevenLabs dependency with ACE-Step 1.5 running on your own computer.

## What this means

- No ElevenLabs key
- No paid music API
- No cloud music-generation account
- Audio is generated by ACE-Step on your own GPU/CPU
- The Android APK is only the controller/player
- The first setup still needs internet to download ACE-Step and its model files

ACE-Step's official requirements are about 10 GB disk for the core models. It supports low-VRAM modes; the official guide says 4-6 GB can run DiT-only with INT8/offload, 6-8 GB can use the 0.6B planning LM, and 12-16 GB can use the 1.7B planning LM.

## Windows

1. Put `install_and_run_windows.ps1` on the PC that will generate the music.
2. Right-click PowerShell or open Terminal in this folder.
3. Run:

```powershell
powershell -ExecutionPolicy Bypass -File .\install_and_run_windows.ps1
```

4. Leave the window open.
5. The script prints your local engine address, for example:

```
http://192.168.1.42:8001
```

6. Connect the phone to the same Wi-Fi.
7. Open SongForge Local and paste that address.
8. Tap **Test local engine**.
9. Generate.

For later sessions, double-click `run_windows.bat`.

## Quality settings

SongForge v0.2 sends:
- ACE-Step 1.5 Turbo
- random seeds
- 8 inference steps
- local 5Hz LM thinking when available
- local auto-lyrics when available
- two candidate generations in Studio Mode
- explicit songwriting/arrangement instructions to reduce repetitive "AI demo" results

For hardware with <=6 GB VRAM, ACE-Step may disable the planning LM. In that case, turn off **Auto-write lyrics locally** and paste your own section-tagged lyrics.

## Security

The launcher binds ACE-Step to your local network on port 8001 with no API authentication so the Android phone can reach it easily. Use it only on a trusted private/home network. Do not port-forward port 8001 to the internet.
